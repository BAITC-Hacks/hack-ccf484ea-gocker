# Учёт личных расходов студента (Telegram Bot & Windows 98 Mini App)

Рабочий прототип системы учёта личных финансов студента, разработанный в соответствии с техническим заданием хакатона без использования ИИ и сторонних платных API.

Решение реализовано в гибридном формате:
1. **Telegram-бот** с интерактивным пошаговым вводом (FSM), меню, разбивкой по категориям, инлайн-кнопками навигации по месяцам и быстрым удалением записей.
2. **Telegram Mini App / Веб-приложение в стиле Windows 98** с аутентичными 3D-рамками, строгим интерфейсом, сегментированными индикаторами прогресса, вкладками и окнами диалогов.
3. **Хранилище данных**: поддержка **PostgreSQL** (для продакшна/Docker) и **SQLite** (для локальной разработки и тестов).
4. **Валюта**: Все суммы и расчёты производятся в **тенге (₸)**. Полностью исключены эмодзи.

---

## Развёртывание через Docker Compose

Для быстрого запуска всей системы (PostgreSQL 16 + Приложение с ботом и веб-интерфейсом):

### 1. Настройка переменных окружения
Скопируйте пример конфигурации:
```bash
cp .env.example .env
```
Укажите ваш `BOT_TOKEN` и (при необходимости) `WEB_APP_URL` в файле `.env`.

### 2. Запуск контейнеров
```bash
docker compose up -d --build
```

Сервер автоматически:
- Запустит контейнер `finance_db` с PostgreSQL 16 и дождётся прохождения проверки работоспособности (healthcheck).
- Сберёт контейнер `finance_app` на базе легковесного образа с `uv`.
- Выполнит миграции базы данных и запустит Telegram-бота вместе с веб-сервером на `http://localhost:8000`.

### 3. Остановка
```bash
docker compose down
```

## Локальный запуск (с менеджером `uv`)

### 1. Установка зависимостей
```bash
uv sync
```

### 2. Запуск приложения

- **Совместный запуск (Telegram-бот + Mini App):**
  ```bash
  uv run python main.py
  ```
- **Запуск только веб-интерфейса / Mini App:**
  ```bash
  uv run python main.py --web-only
  ```
- **Запуск только Telegram-бота:**
  ```bash
  uv run python main.py --bot-only
  ```

## Реализованный функционал

### 1. Основные требования (Раздел 6 ТЗ)
- **Форма ввода расхода**:
  - Принимает положительную сумму (`> 0`), категорию, дату (`ГГГГ-ММ-ДД`) и опциональное описание.
  - Строгая валидация: неположительные числа, пустые категории и некорректные даты отклоняются с понятным пояснением ошибки.
- **Список расходов**:
  - Отображение всех записей за выбранный месяц с детализацией (дата, категория, сумма, комментарий).
  - Удаление любой записи в один клик с мгновенным пересчётом всех итогов.
- **Расчёт итогов и структуры трат**:
  - Подсчёт общего итога за выбранный месяц.
  - Автоматическая группировка и расчёт сумм по категориям с расчётом процентного соотношения.
  - **Математический инвариант:** сумма по всем категориям строго равна общему итогу.
  - Динамическое обновление итогов при добавлении, удалении и смене месяца.
- **Сохранение данных**:
  - Персистентное хранение в PostgreSQL или SQLite с привязкой к пользователю.

### 2. Дополнительные возможности (Раздел 8 ТЗ)
- **Месячный бюджет**: установка лимита расходов на месяц с индикатором остатка и предупреждением о перерасходе.
- **Визуализация структуры расходов**: шкалы категорий и распределения бюджета.
- **Экспорт в CSV**: выгрузка таблицы расходов за текущий месяц в файл прямо в Telegram.
- **Встроенная проверка примера ТЗ**: кнопка «Тестовый пример ТЗ» в боте и в меню Windows 98 для наглядной демонстрации раздела 7.

## Проверочный пример (Раздел 7 ТЗ)

Сценарий проверки расчёта:
1. В выбранном месяце добавляются три расхода:
   - **еда** — `1 500 ₸`
   - **транспорт** — `600 ₸`
   - **еда** — `900 ₸`
   *Результат:* Всего **3 000 ₸**, еда — **2 400 ₸**, транспорт — **600 ₸**.
2. Удаляется расход на `900 ₸`:
   *Результат:* Всего **2 100 ₸**, еда — **1 500 ₸**, транспорт — **600 ₸**.

> Сценарий покрыт автоматическим тестом `tests/test_expenses.py::test_section_7_spec_scenario` и встроен в интерфейс бота (`/test_scenario`) и веб-приложения.
